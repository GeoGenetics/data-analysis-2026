## Repository layout

| Directory | Contents |
| --- | --- |
| `data/` | Datasets used in lectures and exercises |
| `scripts/` | R scripts, R Markdown and notebooks for the demos |
| `exercises/` | Exercise sheets and solutions |
| `slides/` | Lecture slides (PDF) |
| `resources/` | Cheat sheets and reference documents |
| `workspaces/` | Cloud workspace templates (Terraform / Docker) |
| `img/` | Figures produced by the course material |
